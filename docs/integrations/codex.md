# Codex Plugin Package

VAD publishes a local Codex package as a reviewable artifact generated by
`vad.control_plane.codex_package`. The package is not an installer apply path:
operators inspect the generated files, run a dry-run, and then decide whether to
copy them into a Codex plugin location.

## Package Contract

The package id is `vad-codex-local`. It targets Codex and uses the local stdio
command `vad mcp run` with live services disabled by default.

The generated Codex plugin manifest follows the current Codex plugin shape
verified from installed plugin manifests and the plugin-creator spec:

- manifest path: `.codex-plugin/plugin.json`;
- `name`, `version`, `description`, author, metadata, `skills`, `mcpServers`,
  and `interface` fields;
- `skills`: `./skills/`;
- `mcpServers`: `./.mcp.json`;
- no `hooks` or `apps` field because this package does not generate companion
  hook or app files.

The generated local MCP config is:

```json
{
  "mcpServers": {
    "vad": {
      "command": "vad",
      "args": ["mcp", "run"],
      "env": {
        "VAD_LIVE_SERVICES": "disabled"
      }
    }
  }
}
```

## Skill Guidance

The package includes Codex skill guides under `./skills/`:

- Builder: implement small complete VAD slices, read the active plan and tracker,
  use local MCP evidence, and avoid placeholder code.
- Verifier: run proof obligations, inspect artifacts, and report exact command
  evidence for failures.
- Auditor: review policy decisions, signatures, retrospectives, recovery notes,
  and dangerous-tool defaults before accepting completion.

## Dry-Run Review

Installer dry-run output lists the workspace files `.codex-plugin/plugin.json`
and `./.mcp.json`, plus user-scoped review paths under `codex/vad/`. The dry-run
does not write files. Security audit checks reject embedded secret markers,
non-local cloud endpoints, path escapes, and high-risk tools approved by default.

Manual fallback remains:

```bash
vad mcp run
```
