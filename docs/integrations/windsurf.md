# Windsurf Integration Package

VAD provides a local Windsurf package contract generated by
`vad.control_plane.windsurf_package.build_windsurf_package`. The package is a
dry-run artifact for operator review. It does not write Windsurf profile files,
install marketplace MCPs, or approve tools on the operator's behalf.

## Current Windsurf MCP Shape

Windsurf Cascade's current MCP documentation says the user MCP configuration is
stored in `~/.codeium/windsurf/mcp_config.json`. The file uses a top-level
`mcpServers` object.

The generated VAD config is:

```json
{
  "mcpServers": {
    "vad": {
      "command": "vad",
      "args": ["mcp", "run"],
      "env": {
        "VAD_LIVE_SERVICES": "disabled"
      }
    }
  }
}
```

The package id is `vad-windsurf-local`. In dry-run output the profile config is
represented relative to the supplied user config root as
`.codeium/windsurf/mcp_config.json`, so no host profile directory is guessed or
written.

## Rules And Workflow

Windsurf now documents Devin Desktop workspace rules in `.devin/rules/*.md`
with legacy `.windsurf/rules` fallback. The package uses the preferred
workspace rule location and generates:

- `.devin/rules/vad-builder.md`: tracker reading, proof obligations, local MCP
  evidence, complete-slice expectations, and high-risk mutation gating.
- `.devin/rules/vad-verifier.md`: proof execution, evidence inspection, exact
  command reporting, and incomplete-work criteria.
- `.devin/rules/vad-auditor.md`: policy, signature, retrospective, recovery,
  local-only, and high-risk approval review.

The package also generates `.windsurf/workflows/vad-verify.md`, a manual
`/vad-verify` workflow for running focused proof checks and the full
Docker-under-WSL gate before a tracker item is marked complete.

## Dry-Run Review

Installer dry-run output lists:

- user `.codeium/windsurf/mcp_config.json`;
- workspace `.devin/rules/vad-builder.md`;
- workspace `.devin/rules/vad-verifier.md`;
- workspace `.devin/rules/vad-auditor.md`;
- workspace `.windsurf/workflows/vad-verify.md`.

Security audit checks reject embedded secret markers, non-local cloud endpoints,
path escapes, and high-risk tools approved by default. VAD package metadata
leaves every tool unapproved by default; operators should still review Windsurf
MCP tool toggles in Cascade before use.

Manual fallback remains:

```bash
vad mcp run
```
