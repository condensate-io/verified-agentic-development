# VS Code Integration Package

VAD provides a local VS Code package contract generated by
`vad.control_plane.vscode_package.build_vscode_package`. The package is a
dry-run artifact for operator review. It does not write VS Code profile files,
start servers automatically, or bypass VS Code trust prompts.

## Current VS Code MCP Shape

The current VS Code MCP documentation says workspace MCP server configuration
belongs in `.vscode/mcp.json`. User-profile MCP configuration is opened through
the `MCP: Open User Configuration` command because the concrete profile folder
is managed by VS Code and can vary by profile.

VS Code uses a top-level `servers` object in `mcp.json`. The generated VAD
workspace config is:

```json
{
  "servers": {
    "vad": {
      "type": "stdio",
      "command": "vad",
      "args": ["mcp", "run"],
      "env": {
        "VAD_LIVE_SERVICES": "disabled"
      }
    }
  }
}
```

The package id is `vad-vscode-local`. The manifest records both the workspace
path `.vscode/mcp.json` and the user-profile review path `vscode/mcp.json` so
dry-run output can show exactly what would be reviewed without guessing the
active VS Code profile directory.

## Dashboard Task

The package also generates `.vscode/tasks.json` with the task label
`VAD: Serve dashboard`. The task runs:

```bash
vad ui serve --host 127.0.0.1 --port 8080 --seed-level3-demo
```

After starting the task, open `http://127.0.0.1:8080` in a browser or VS Code
preview. This is the documented dashboard equivalent for VS Code: the VAD
dashboard remains the same local HTTP UI exposed by `vad ui serve`, and VS Code
only provides a convenient task to start it.

## Trust And Review

Local MCP servers can run commands on the operator machine, so review
`.vscode/mcp.json` before starting the server and use VS Code's MCP trust prompt
as the final local confirmation. The generated config embeds no API keys,
tokens, passwords, non-local HTTP endpoints, or auto-approved high-risk tools.

Installer dry-run output lists:

- workspace `.vscode/mcp.json`;
- workspace `.vscode/tasks.json`;
- user-profile review path `vscode/mcp.json`.

No files are written during dry-run. Manual fallback remains:

```bash
vad mcp run
```
