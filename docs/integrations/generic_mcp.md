# Generic MCP Package

VAD provides a generic stdio MCP package for clients that support Model Context Protocol server configuration but do not have a dedicated VAD integration package yet.

## Package Contract

The package is generated by `vad.control_plane.generic_mcp_package.build_generic_mcp_package`.

- Plugin id: `vad-generic-mcp`.
- Target client: `generic_mcp`.
- Transport: local stdio.
- Command: `vad mcp run`.
- Live services default: `VAD_LIVE_SERVICES=disabled`.
- High-risk tools are never approved by default.

## Stdio Client Snippet

Clients that use the common `mcpServers` shape can add:

```json
{
  "mcpServers": {
    "vad": {
      "command": "vad",
      "args": ["mcp", "run"],
      "env": {
        "VAD_LIVE_SERVICES": "disabled"
      }
    }
  }
}
```

Clients that expect a direct server map can use:

```json
{
  "vad": {
    "command": "vad",
    "args": ["mcp", "run"],
    "env": {
      "VAD_LIVE_SERVICES": "disabled"
    }
  }
}
```

## Manual Fallback

Run the MCP server directly when a client cannot consume a config file:

```bash
vad mcp run
```

The server exposes safe observer tools by default. Tools such as repository patching and signature verification remain hidden until the caller supplies the matching role and explicit high-risk approval for that call.
