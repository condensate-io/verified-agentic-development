# Cursor Integration Package

VAD provides a local Cursor package contract generated by
`vad.control_plane.cursor_package.build_cursor_package`. The package is a
dry-run artifact for operator review. It does not write Cursor profile files,
install marketplace plugins, or approve MCP tools on the operator's behalf.

## Current Cursor MCP Shape

Cursor's current MCP documentation says project MCP configuration belongs in
`.cursor/mcp.json` and global MCP configuration belongs in `~/.cursor/mcp.json`.
Cursor uses a top-level `mcpServers` object for local stdio servers.

The generated project/global config is:

```json
{
  "mcpServers": {
    "vad": {
      "type": "stdio",
      "command": "vad",
      "args": ["mcp", "run"],
      "env": {
        "VAD_LIVE_SERVICES": "disabled"
      }
    }
  }
}
```

The package id is `vad-cursor-local`. The manifest records the project path
`.cursor/mcp.json` and the global review path `~/.cursor/mcp.json`. In dry-run
output the global path is represented relative to the supplied user config root
as `.cursor/mcp.json`, so no host profile directory is guessed or written.

## Rules

Cursor project rules are `.mdc` files under `.cursor/rules`. The package
generates:

- `.cursor/rules/vad-builder.mdc`: builder workflow, tracker reading, proof
  obligations, and high-risk mutation gating.
- `.cursor/rules/vad-verifier.mdc`: proof execution, evidence inspection, and
  incomplete-work criteria.
- `.cursor/rules/vad-auditor.mdc`: policy, signature, retrospective, recovery,
  local-only, and high-risk approval review.

Each rule includes Cursor frontmatter with `description` and
`alwaysApply: false`, so Cursor can apply the rule based on relevance or manual
selection rather than forcing every chat to carry all VAD guidance.

## Dry-Run Review

Installer dry-run output lists:

- project `.cursor/mcp.json`;
- project `.cursor/rules/vad-builder.mdc`;
- project `.cursor/rules/vad-verifier.mdc`;
- project `.cursor/rules/vad-auditor.mdc`;
- global review path `.cursor/mcp.json` under the user config root.

Security audit checks reject embedded secret markers, non-local cloud endpoints,
path escapes, and high-risk tools approved by default. Cursor asks for approval
before using MCP tools by default; VAD package metadata also leaves every tool
unapproved by default.

Manual fallback remains:

```bash
vad mcp run
```
