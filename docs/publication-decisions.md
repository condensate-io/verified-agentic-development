# Publication Decision Records

These records document the current publication posture for the local-first VAD
packages. They do not approve publishing. Any registry upload, marketplace
submission, signed release, or public artifact distribution requires explicit human approval after artifact review, digest report review, secret scan, and rollback/uninstall notes.

Decision values:

- `approved-manual`: local repository/manual release artifact is acceptable after human approval.
- `deferred`: technically possible later, but not approved for the current local distribution.
- `not-applicable`: the target registry does not match the package shape.
- `blocked`: no first-class package exists or current evidence is insufficient.

## Human Approval Gate

Before any deferred or manual decision becomes a publication action, the release
guardian must confirm all of the following:

- artifact paths and digest report were generated by `build_reproducible_artifacts`;
- generated artifacts and configs passed secret scanning;
- dry-run installer output, rollback or uninstall path, and manual fallback are documented;
- target registry or marketplace requirements were rechecked for the exact
  package type on the release date;
- the action is explicitly approved by a human operator.

No current VAD command uploads packages, opens marketplace submissions,
publishes npm/PyPI artifacts, or marks marketplace acceptance as complete.
